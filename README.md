# 🕒 Digital Clock with Real-Time Date & Time

A clean, light-weight, and accurate GUI-based Digital Clock application built using Python. This application displays real-time updates for hours, minutes, seconds, 12-hour format (AM/PM), as well as the exact day, month, and year.

---

## ✨ Features

* **Real-Time Display:** Live updating time with seconds precision.
* **12-Hour Format:** Clearly indicates `AM` and `PM`.
* **Full Date & Calendar Details:** Displays current Day, Month, and Year.
* **Simple & Intuitive UI:** Built with standard Python GUI components for smooth performance.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Libraries Used:** 
  * `tkinter` (Standard Python GUI library)
  * `time` / `datetime` (For fetching accurate system date & time)
